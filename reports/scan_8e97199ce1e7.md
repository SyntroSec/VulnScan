#### HTTP Server Header Disclosure

- **CVE(s):** n/a
- **Detected:** 2026-11-06T20:32:04.652179+00:00

**Description**

The HTTP response discloses a Server header that reveals the web server product and often a version string. Attackers use this for targeted exploit selection.

**Evidence**

```

X-Powered-By: ASP.NET
```

**Remediation**

Remove or obfuscate the Server header at the reverse proxy or application layer. Prefer a generic value and keep components patched.

#### Missing Common HTTP Security Headers

- **ID:** `SIG-HTTP-MISSING-SECURITY-HEADERS`

- **Location:** `127.0.0.1:80/tcp`
- **CVE(s):** n/a
- **Detected:** 2026-11-06T20:32:04.652197+00:00

**Description**

One or more widely recommended HTTP security headers were not observed in the response. Missing headers increase risk of clickjacking, MIME sniffing, and related client-side attacks.

**Evidence**

```
HTTP/1.1 200 OK
Server: Microsoft-IIS/10.0
X-Powered-By: ASP.NET
Missing patterns: (?i)strict-transport-security:, (?i)x-content-type-options:, (?i)x-frame-options:, (?i)content-security-policy:
```

**Remediation**

Configure the web server or reverse proxy to emit HSTS (HTTPS only), X-Content-Type-Options, X-Frame-Options (or CSP frame-ancestors), and a Content-Security-Policy appropriate for the application.

**References**

- https://owasp.org/www-project-secure-headers/
